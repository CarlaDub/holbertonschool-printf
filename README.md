# Projet printf

## Description du projet et de la fonction printf

### Fonctions de print_chars.c

- `print_char` : affiche un seul caractère avec `%c`.
- `print_string` : affiche une chaîne de caractères avec `%s`.
- `print_percent` : affiche le symbole `%` avec `%%`, sans récupérer d'argument.

Chaque fonction retourne le nombre de caractères affichés en cas de réussite.
